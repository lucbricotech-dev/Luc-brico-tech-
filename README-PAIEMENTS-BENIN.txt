LUC BRICO-TECH — Paiements Bénin

Modes : Espèces, MTN MoMo, Moov Money, Celtiis Cash, virement bancaire,
carte bancaire, chèque bancaire et autre.

Une facture peut recevoir plusieurs paiements. Le montant payé et le statut
sont recalculés automatiquement après ajout, modification ou suppression.

Installation :
1. Supabase > SQL Editor : exécuter supabase_payment_migration.sql.
2. Remplacer script.js dans le projet par celui de ce patch.
3. Commit / push GitHub puis laisser Vercel redéployer.
